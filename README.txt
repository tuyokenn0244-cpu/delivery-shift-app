配送シフト 修正版 v10

【更新方法】
1. このZIPを新しいフォルダに「すべて展開」します。
2. delivery-shift-app-mainフォルダを開きます。
3. GitHubのdelivery-shift-appで「＋」→ Upload files を開きます。
4. フォルダの中身を全部ドラッグします。icons、vendor、DeliveryShiftPWAもフォルダのまま入れます。
   vendorには読み取りに必要なファイルが入っています。必ずアップロードしてください。
   app.jsやindex.htmlに (1) などの番号を付けないでください。
5. Commit changes を押します。
6. GitHub Pagesの反映後、アプリを再読み込みします。上部の「自分用 · v10」を確認してください。
   ブラウザのサイトデータは削除しないでください。登録した勤務も消えます。

【今回の写真での操作】
1. 勤務表の年月を2026年9月にします。
2. 「勤務表を撮る / 選ぶ」で元の写真を選びます。
3. 写真の「竹谷 健」の中央をタップします。No.20は固定していません。
4. 見出しの一番左の「11」をタップします。
5. 写真の最初の日付に11、最後の日付に20を入力します。
6. 「この位置で読み取る」を押します。
7. 入力欄とその下の原本のマスを照合します。低い確信度や未読取はオレンジ枠になります。
8. 2便・3便とも写真の空欄を確認できた日は「休み」に自動チェックされます。原本と照合し、違う場合はチェックを外してください。
9. 「確認した内容をカレンダーへ登録」を押します。

【変更した仕組み】
日付や氏名の文字認識への依存をやめ、利用者のタップ位置と日付範囲から表の枠線を検出します。
本人の2便・3便を日付別のマスに切り分け、数字を1マスずつ拡大して読みます。
範囲は必ず写真と一致させてください。枠線を確認できない場合は自動登録しません。
OCRライブラリと英数字の学習データを同梱し、外部CDNへの依存をなくしました。
写真は端末内で処理します。読み取り用のサーバーには送信しません。
従来の端末内の勤務データ・コース別の出勤時間は維持します。
未設定のコースの出勤時間は推測しません。
初期状態に入っていた9月1〜10日の勤務は引き続き原本照合が必要です。出勤時間は今回提供された掲示表に合わせました。
