配送シフト 修正版 v6

【更新方法（GitHub Pages）】
1. このZIPを展開します。
2. delivery-shift-app-mainフォルダを開きます。
3. GitHubのdelivery-shift-appリポジトリで Add file → Upload files を選びます。
4. フォルダの中身（app.js、index.html、style.css、sw.js、manifest.webmanifest、iconsフォルダ、DeliveryShiftPWAフォルダ）をアップロードして Commit changes を押します。
   delivery-shift-app-mainフォルダ自体を追加しないでください。
5. GitHub Pagesの更新完了後、同じブラウザでサイトを再読み込みします。
   ブラウザのサイトデータは消さないでください。登録した勤務や時間も消えます。

【使い方】
・氏名を保存し、写真の勤務表に書かれた年月を選びます。
・「勤務表を撮る / 選ぶ」で画像を指定します。
・読み取り候補の数字と日付を原本と照合します。空欄は未読取です。
・休みは自分でチェックします。休みの行にはコースを入れないでください。
・読み取れない場合は「手入力で登録」で続けられます。
・空欄の既存勤務は変更しません。片方の便だけ入力した場合、もう片方の既存便は保持します。
・出勤時間は元のコース別時間表を使います。不明なコースの時間は推測しません。

【修正内容】
・未読取の空欄を自動で休みにしない。
・年月を明示して登録先を固定。候補を開いてから月を移動しても登録先は変わらない。
・存在しない日付や不正なコース、休みとコースの同時入力を防止。
・氏名の曖昧一致を自動採用せず、本人の位置に近い便の行を優先。
・列の欠落で日付がずれる危険な連番推測を廃止。日付を確かめられない場合は手入力へ。
・前の写真の認識結果が次の写真の失敗時に表示される問題を修正。
・読み取り中の重複操作を防止。失敗後も手入力できる。
・削除済みの勤務・出勤時間が再起動で復活する問題を修正。
・不足していたルートのアイコンを追加。2つの入口を同じ版に統一。
・他アプリのキャッシュを消さないよう修正。

更新後も実際の勤務表と照合してください。
