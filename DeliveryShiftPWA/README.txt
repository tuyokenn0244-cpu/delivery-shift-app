配送シフト PWA（Windows → iPhone用）
====================================

このフォルダは、iPhoneのSafariから「ホーム画面に追加」して使えるWebアプリです。

【入っている機能】
・竹谷 健 の氏名を初期登録
・2026年9月1〜10日の2便 / 3便 / 休みデータ
・コース番号に応じた出勤時間表示
・氏名の保存
・iPhoneのカメラ / 写真選択
・OCRによる勤務表の読取候補作成
・読取結果を修正してカレンダーへ登録
・コース別出勤時間の追加 / 編集
・端末内保存（localStorage）

※OCRは勤務表の罫線・傾き・光の反射などで誤認識する可能性があるため、必ず確認画面を通してから登録する仕様です。

--------------------------------------------------
一番簡単な入れ方（Windowsしかない場合）
--------------------------------------------------

PWAのカメラ/OCR/オフライン機能を安定して使うには HTTPS で公開する必要があります。
このフォルダ一式を、HTTPSで静的サイトを公開できるサービスへアップロードしてください。

例：GitHub Pagesを使う場合
1. GitHubのアカウントを作る
2. 新しいRepositoryを作る（例 delivery-shift）
3. このフォルダ内の index.html / app.js / style.css / manifest.webmanifest / sw.js / icons フォルダをアップロード
4. Repositoryの Settings → Pages を開く
5. Branchを main、フォルダを /(root) にして公開
6. 表示された https://... のURLをiPhoneのSafariで開く
7. Safari下部の共有ボタン →「ホーム画面に追加」
8. 「配送シフト」のアイコンがiPhoneに追加される

【重要】
・Safariで開いて「ホーム画面に追加」してください。
・最初のOCR実行時にはTesseract.jsを読み込むためインターネット接続が必要です。
・勤務データはブラウザ内に保存されるので、SafariのWebサイトデータを削除すると消える場合があります。
・現在の出勤時間は2便（200番台）のコース番号から判定しています。
